# نظام الحضور والنبطشيات والسهر الموحد (HTML / CSS / JS + Google Sheets Sync)

تطبيق ويب متكامل مبني بـ **HTML و CSS و JavaScript النقي** يوفّر صفحة تسجيل دخول آمنة، وواجهة **إكسيل داخلية تفاعلية** تجمع كشوف **الحضور والنبطشيات والسهر والمستحقات المالية** في ورقة واحدة، مع **مزامنة سحابية تلقائية لنفس المستخدم عبر أكثر من جهاز** باستخدام **Google Sheets (Apps Script)**.

---

## المزايا الرئيسية

1. **ورقة موحدة شاملة (الحضور + النبطشيات + السهر + الماليات):**
   - أعمدة بيانات الموظف المثبتة أثناء التمرير الأفقي (`الكود`، `اسم الموظف`، `القسم`).
   - شبكة أيام الشهر كاملة (`1` إلى `28/29/30/31` ديناميكياً حسب الشهر والسنة مع تمييز أيام الجمعة).
   - **دعم الرموز المفردة والمدمجة في نفس اليوم:**
     - `ح` = حضور يوم
     - `ن` = نبطشية (أو `ن2` = نبطشيتان)
     - `س` = سهر بالوحدة الافتراضية، أو `س3` / `س2.5` = سهر بعدد ساعات محدد
     - `ح+ن` = حضور + نبطشية في نفس اليوم
     - `ح+س` أو `ح+س3` = حضور + 3 ساعات سهر في نفس اليوم
     - `ح+ن+س2` = حضور + نبطشية + ساعتان سهر في نفس اليوم
     - `غ` = غياب | `إ` = إجازة | `م` = مأمورية | `ر` = راحة | `ع` = عطلة
   - تجميع تلقائي فوري لأعداد (الحضور، النبطشيات، السهر، الغياب، الإجازات) وحساب المستحقات المالية وصافي المستحق لكل موظف وإجمالي الكشف بالكامل.

2. **واجهة إكسيل داخلية متكاملة:**
   - شريط صيغة `fx` يدعم المعادلات الحسابية ودوال الإكسيل مثل `=SUM(A1:A10)` و `=AVERAGE(...)` و `=MIN(...)` و `=MAX(...)` و `=IF(...)`.
   - التنقل بالأسهم و `Enter` و `Tab` و `F2`، وسحب **مقبض التعبئة السريعة (Fill Handle)** لتكرار القيم والرموز.
   - نسخ ولصق مباشر `Ctrl+C` / `Ctrl+V` متوافق مع برنامج Microsoft Excel الحقيقي.
   - تعدد الأوراق في الشريط السفلي (أوراق شهور متعددة + أوراق إكسيل حرة + ترحيل الموظفين للشهر الجديد بضغطة زر).
   - تصدير إلى ملف Excel منسق (`.xls`) وملف `CSV`، بالإضافة إلى وضع **الطباعة الرسمية (A4 Landscape)** مع الترويسة والتوقيعات.

3. **مزامنة بيانات نفس المستخدم بين أكثر من جهاز:**
   - عند ربط رابط **Google Apps Script Web App**، يتم حفظ حساب المستخدم ومصنفه بالكامل في Google Sheets (مع تقسيم تلقائي للبيانات الضخمة لتجاوز حد الخلية 50,000 حرف).
   - عند فتح الموقع من جهاز آخر وتسجيل الدخول بنفس اسم المستخدم وكلمة المرور، يتم جلب آخر نسخة ومزامنة التعديلات تلقائياً في الخلفية.

---

## طريقة التشغيل والربط السحابي (خطوة بخطوة)

### أولاً: التشغيل الفوري
افتح الملف `index.html` مباشرة في أي متصفح حديث (Chrome / Edge / Firefox)، أو ارفع المجلد على أي استضافة ثابتة مجانية مثل **GitHub Pages** أو **Netlify**.

### ثانياً: تفعيل المزامنة بين الأجهزة عبر Google Sheets (مجاناً)
1. افتح جدول Google Sheet جديد عبر الرابط `https://sheets.new`.
2. من القائمة العلوية اختر: **Extensions (الإضافات) -> Apps Script**.
3. انسخ الكود الموجود في ملف `google-apps-script/Code.gs` (أو اضغط زر **نسخ كود Google Apps Script الجاهز** من نافذة `☁️ ربط الأجهزة` داخل الموقع) والصقه بالكامل ثم اضغط حفظ.
4. اضغط **Deploy (نشر) -> New deployment (نشر جديد)**:
   - اختر النوع: **Web app (تطبيق ويب)**.
   - اجعل **Execute as**: `Me`.
   - اجعل **Who has access**: `Anyone` *(ضروري للسماح بالاتصال من المتصفح)*.
5. انسخ رابط الـ Web App الناتج (ينتهي بـ `/exec`):
   - يمكنك لصقه مباشرة داخل نافذة **ربط الأجهزة** في الموقع، ثم الضغط على **🔗 نسخ رابط الدخول السريع للأجهزة الأخرى** لفتحه على هاتفك أو حاسوبك الآخر فيتصل تلقائياً.
   - أو يمكنك وضعه مرة واحدة داخل `DEFAULT_SCRIPT_URL` في ملف `js/config.js` قبل رفع الموقع على استضافة ليعمل تلقائياً على كل الأجهزة دون إدخال الرابط يدوياً.
